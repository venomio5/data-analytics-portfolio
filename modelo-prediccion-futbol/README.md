# Modelo de Predicción de Fútbol

El objetivo del proyecto era encontrar una ventaja frente al mercado mediante el análisis de datos. Desarrollé en Python un modelo que integra rendimiento individual, fatiga, ritmo y contexto de partido, con componentes entrenados mediante algoritmos de machine learning, y utiliza sus estimaciones en simulaciones Monte Carlo. En un backtest de más de 5,000 apuestas, alcanzó un ROI superior al 8% y una mejor calibración probabilística que el mercado.

Estructura del repositorio:

```
├── 01_assets/       # Recursos visuales y gráficos del proyecto
├── 02_data/         # Datos, predicciones y modelos entrenados utilizados en los análisis
├── 03_research/     # Notebooks que documentan el desarrollo y los componentes del modelo
├── 04_pipeline/     # Pipeline de predicción, simulación, apuestas y backtesting
├── 05_results/      # Evaluación de xG, probabilidades y rentabilidad histórica
└── README.md
```
